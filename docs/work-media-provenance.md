## Presentation and limits

The opening map shows a concrete personally attributed output. Paid Entropy work leads; videos and AIRC reels follow, then working independent tools and the visualization archive. Atlas remains bounded supporting evidence. Wikimedia, Padua, education, investigations, Telegram and experimental projects remain discoverable.

The hero has manual tabs with arrow/Home/End navigation and no automatic rotation. Collections use native disclosures, work without JavaScript and keep the initial view small. On mobile, the homepage chart previews use a native horizontal strip; focus disables snapping so keyboard scrolling can reveal every preview. Motion is brief and respects reduced-motion settings. The screen stylesheet does not change CV print styling.

Captures and metadata are dated evidence, not a promise that an external platform is unchanged. No push, deployment, account edit, outreach or repository-visibility change is included. Design and recruiting conversion have not been measured; this is a reviewable local implementation.
